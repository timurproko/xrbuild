# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Hands mounts one global None-or-installed-plugin selector below Source with settings, status and independent revision-safe next-run saves.
- Optional mesh processing consumes the final sampled skeleton without changing joints, gestures, pointer state or application code.
- Managed desktop runs own one authenticated sidecar with bounded pending work, validated two-hand mesh buffers and lifecycle cleanup.
- Missing, late, malformed or failed mesh output visibly falls back to skeleton drawing without blocking input or app launch.
- Standard SDK mesh drawing uses common mapping and global appearance, honors visual opt-out and disposes retired geometry.
- Browser previews, published web builds, offline packages and unmanaged runs stay skeleton-only without mesh credentials or launch refusal.
- Product discovery reads metadata only and ships no real processor, model, automatic installation or provider-specific runtime branch.
