# Simplify worktree guidance

## Why

Repository instructions require an advisory inventory to display current immediately after a successful native attachment. Temporary runtime coordination can make every row unverifiable and unnecessarily stop an otherwise valid task. Worktree coordination belongs to the agent runtime, not repository-specific prose.

## What Changes

- Use the shared minimal worktree guidance for runtime enter, attach, and detach commands.
- Remove the second inventory approval gate and duplicated internal recovery recipes.
- Keep dependency setup, private-clone independence, preservation, and merge authority unchanged.
- Require a compatible installed runtime before integrating this instruction migration.

## Impact

Agent instructions and their focused regression test only. No product, canonical spec, private workspace, cleanup implementation, or installation changes. The maintainer approved this migration alongside the runtime command interface on 2026-11-11.
