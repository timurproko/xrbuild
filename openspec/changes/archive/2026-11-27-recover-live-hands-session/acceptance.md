# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Transient malformed observations clear lost hands without synthetic substitution, with visible kind, joint and count diagnostics.
- Recent rejection rates reset on healthy frames; persistent invalid streams and prolonged stalls have bounded failure paths.
- Owned workers are joined before release, including launcher crashes and partial stdout during forced termination.
- Same-page recovery, passive reload and explicit same-panel takeover do not overlap acquisition or reuse retired epochs.
- Filtered packets cannot masquerade as original raw recordings; admitted intact peers retain an honest observed frame rate.
