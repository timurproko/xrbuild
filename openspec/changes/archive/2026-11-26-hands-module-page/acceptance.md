# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Hands has Record as its only tool tab, and retired diagnostic and legacy page routes return not found without redirects.
- The merged global adjustment component owns both right-side sections, resets and Apply while preserving independent source drafts and revision-safe delivery handling.
- Legacy CSV, RGB, RGB-D and paired recordings retain their original spaces and safe playback without capture, inference or fusion startup.
- Calibration output and identity bindings remain documented for an independent module; future-provider algorithms and ordinary native Synthetic remain preserved without browser fixtures.
- New provider recording stays gated on a compatible live producer, with bounded raw data, frozen profiles and explicit export-loss warnings.
