# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Declared number, select and boolean controls match the Hands style, fit narrow themed sidebars and reset only the selected plugin settings.
- Finished edits autosave without routine Save or Reload, while intermediate input, unrelated profile fields and newer pending intentions remain protected.
- Current run, saved revision and requested/applied generations gate Applied; Preparing and explicit failure Retry remain distinct from persistence and drawing.
- No session, viewport, server or SDK code changes are included; standalone Hands delivery uses the existing API response shapes supplied by the parallel integration.
