# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Default retains the reference geometry, materials, text metrics and authored layout without changing renderer defaults.
- Chamfer covers all controls, variants, text/icon primitives, glass edges and physical feedback cues with a coherent mesh style.
- Scoped provider and imperative selection preserve live control identity, held capture, values and owned-resource cleanup.
- UI Kit and Launcher declare a Default fallback and accept controlled theme choices without additional UI or settings infrastructure.
- Both styles retain mouse and hand-only event order, values, sounds and projection behavior in perspective, orthographic and stereo.
- Launcher retains catalog reconciliation, paging, release actions and accepted navigation timing across theme changes.
- Public app imports remain side-effect-free and production builds retain relative assets and standalone icons.
