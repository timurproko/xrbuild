# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Identity defaults preserve frame bits and standard skeleton materials, colours and drawing geometry.
- Wrist-relative size and panel-space offset adjust native and WebXR joints and optional positions before shared interaction.
- Appearance edits change only drawing; geometry Apply releases held interactions and resets filters without synthetic clicks.
- Running profile updates require the current run and newer sequence, with SDK acknowledgement distinguishing applied from saved.
- Native, dev and browser launches receive profiles, while desktop, headset and published output freeze portable build-time snapshots.
- Hands sections use shared controls, per-group resets and explicit Apply, and can move into a future side panel without rebuilding.
