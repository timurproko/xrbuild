# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Explicit Hands sessions own optional mesh gateways; idle navigation and configuration saves start no provider or processor.
- Hands GET, PUT and retry operations follow the active session without restarting acquisition or sharing its camera lease with mesh.
- Both consumers draw final-pose skin through current wrist translation and orientation without mutating skeleton input or held interactions.
- Source-snapshot reuse is bounded by the named 100 ms constant and a 10 mm post-compensation residual, with retired generations rejected.
- Opaque single-sided skin follows bone colour while Joints, Bones and skeleton opacity retain independent behavior.
- Fast articulation can still omit skin under the residual guard; rigid compensation does not provide newly fitted fingers.
