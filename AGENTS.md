# XR Build agent work

The ignored `.xrbuild/` folder is an independent private workspace clone, not part of core Git history, a submodule or a junction. Follow the Workspace section of `.claude/CLAUDE.md`, the private clone's `CLAUDE.md` and each affected plugin's instructions. Change private files only in the task's independently provisioned clone inside its linked worktree. Never clean up a worktree containing private workspace data or an `.artifacts/KEEP` preservation marker.

Before planning or changing this repository, read `.claude/CLAUDE.md` and `.claude/skills/change-delivery/SKILL.md`. Keep the primary checkout on `main`. When asked to deliver a task, first run the worktree sweep and create or cleanly re-enter its `<type>/<short-desc>` branch with `pnpm worktree enter <type>/<short-desc>`. In an active A1 session, bind the returned absolute root with `a1 session link-worktree <absolute-path>`, then require `a1 session worktrees` to display that exact path and branch as `current` before edits. Re-link and confirm on resume or task switch; if native linking of this task's worktree is unavailable, fails or displays another worktree, stop. A stale entry for some other worktree (its directory is gone; `git worktree list` marks it `prunable`) is never a blocker: run `git worktree prune` from the primary checkout, rerun the inventory, and continue. Linking does not authorize cleanup or merge and may not change every tool's cwd, so use explicit absolute worktree paths for all file and Git operations. Never edit the primary checkout or another task's worktree. Only the maintainer chooses when to merge implementation PRs.
